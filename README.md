# Keelers Oven

Website for Keelers Oven, a small-batch home bakery — fresh breads, cookies, and pastries sold at local farmers markets.

Built with [Vue 3](https://vuejs.org/), [Vue Router](https://router.vuejs.org/), and [Vite](https://vite.dev/).

## Development

```sh
npm install
npm run dev
```

## Build

```sh
npm run build
```

## Deployment

Pushes to `main` are automatically built and deployed to GitHub Pages at
<https://jaridkg.github.io/KeelersOven/> via the workflow in
`.github/workflows/deploy.yml`. (In the repo settings, **Pages → Source** must
be set to **GitHub Actions**.)

## Pages

- **Home** — intro and highlights
- **Products** — baked goods and prices (placeholder content for now)
- **Farmers Markets** — where and when to find us
- **Contact** — email, phone, and social links (placeholder for now)
